Entry for the [make.fun](https://make.fun) bounty
[One Emoji, One Dream Vacation](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35):
send exactly one emoji, nothing else, standing in for the trip of your dreams.

`main.py` (pure Python standard library, no dependencies) writes a single
emoji to `/output/entry.txt` — 🌅 (U+1F305, sunrise over the sea), the
golden-hour moment every dream vacation is really about. One codepoint,
no text, no spaces.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
